# 🧩 국기 조각 퀴즈

국기의 일부분만 보고 어느 나라인지 맞히는 퀴즈입니다. 어려우면 힌트를 누르세요. 국기가 단계별로 더 보입니다.

**바로 하기 → https://hoonikims.github.io/national-flag-quiz/**

## 모드

| 모드 | 설명 |
|---|---|
| 🧩 조각 맞히기 | 국기 일부분을 크게 확대해서 보여 줍니다. 힌트를 누를 때마다 국기가 더 보입니다. |
| 🏳️ 국기 맞히기 | 국기 전체를 보고 맞힙니다. |
| 📖 국기 도감 | 194개국 국기를 구경합니다. 이름을 가리고 연습할 수도 있습니다. |

답은 **직접 쓰기**(타이핑)나 **보기에서 고르기** 중에서 고를 수 있습니다.

## 점수

- **속도 점수**: 2초 안에 맞히면 100점이고, 그 뒤로는 1초마다 4점씩 줄어듭니다(최소 10점).
- **힌트**: 하나 쓸 때마다 10%씩 줄어듭니다(최소 40%).
- **콤보**: 2연속 정답부터 +10, 3연속 +20 … 최대 +50점을 더 줍니다.
- **다시 나온 국기**: 틀린 국기는 4문제 뒤에 다시 나오고, 점수는 절반입니다.

고른 국기를 **전부 맞혀야** 한 판이 끝납니다.

## 난이도 (누적)

| 난이도 | 국기 수 | 포함 범위 |
|---|---|---|
| 🙂 쉬움 | 34 | 쉬움 |
| 😎 보통 | 70 | 쉬움 + 보통 |
| 🔥 어려움 | 139 | 쉬움 + 보통 + 어려움 |
| 🌍 전 세계 | 194 | UN 회원국 193개국 + 바티칸 |

한 번이라도 맞힌 국기는 **정복**으로 기록됩니다. 기록은 이 브라우저에 저장됩니다. "🎯 아직 못 맞힌 국기"를 고르면 남은 국기만 나옵니다.

## 실행

설치할 것이 없습니다. `index.html`을 브라우저로 열면 됩니다. 국기 이미지는 `flags/` 폴더에 들어 있어서 인터넷 없이도 동작합니다.
